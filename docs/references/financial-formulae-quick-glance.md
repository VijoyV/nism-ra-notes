## Chapter 3: Terminology in Equity and Debt Markets

| No. | Term / Description |
| :---: | :--- |
| 1 | **Equity Share Capital** – The nominal or par value of the company's ownership capital, calculated as shares issued multiplied by face value. |
| | $\text{Equity Share Capital} = \text{Number of Shares Issued} \times \text{Face Value}$ |
| 2 | **Book Value Per Share** – The theoretical amount each share would receive if the company were liquidated, derived from net worth divided by outstanding shares. |
| | $\text{Book Value Per Share} = \frac{\text{Net Worth}}{\text{Number of Outstanding Shares}}$ |
| 3 | **Market Capitalization** – The total market value of a company's outstanding equity, calculated as market price per share times total shares. |
| | $\text{Market Cap} = \text{Market Price Per Share} \times \text{Total Outstanding Shares}$ |
| 4 | **Enterprise Value (Standalone)** – The total cost to acquire the entire business, reflecting its capital structure; calculated as equity plus debt minus cash. |
| | $\text{EV} = (\text{Market Value of Equity} + \text{Market Value of Debt}) - \text{Cash and Equivalents}$ |
| 5 | **Earnings Per Share (EPS)** – The profit earned for each outstanding share of common stock. |
| | $\text{EPS} = \frac{\text{Net Profit}}{\text{Number of Shares Outstanding}}$ |
| 6 | **Dividend Payout Ratio** – The percentage of net income distributed to shareholders as dividends. |
| | $\text{Dividend Payout Ratio} = \frac{\text{Dividend Per Share}}{\text{EPS}}$ |
| 7 | **Price to Earnings (PE) Ratio** – A valuation multiple showing how much investors pay per rupee of earnings. |
| | $\text{PE Ratio} = \frac{\text{Market Price Per Share}}{\text{EPS}}$ |
| 8 | **Price to Sales (P/S) Ratio** – A valuation metric useful for companies with negative earnings or temporary losses. |
| | $\text{P/S Ratio} = \frac{\text{Market Capitalization}}{\text{Annual Net Sales}}$ |
| 9 | **Price to Book Value (P/BV) Ratio** – Compares market price to the accounting (book) value of the company's assets. |
| | $\text{P/BV Ratio} = \frac{\text{Current Market Price}}{\text{Book Value Per Share}}$ |
| 10 | **Current Yield (Bonds)** – A simple measure of a bond's annual income return based on its current market price. |
| | $\text{Current Yield} = \frac{\text{Annual Coupon}}{\text{Current Market Price}}$ |
| 11 | **Holding Period Return (HPR)** – The total return earned from an investment over the period it was held, including coupon, reinvestment income, and price change. |
| | $\text{HPR} = \frac{\text{Coupon} + \text{Reinvestment Income} + (\text{Sale Price} - \text{Purchase Price})}{\text{Purchase Price}}$ |
| 12 | **Modified Duration** – Measures a bond's price sensitivity to a 1% change in interest rates, where $y$ is the yield. |
| | $\text{Modified Duration} = \frac{\text{Macaulay's Duration}}{(1 + y)}$ |

## Chapter 8: Company Analysis – Financial Analysis

| No. | Term / Description |
| :---: | :--- |
| 1 | **EBITDA Margin** – Evaluates operational efficiency by excluding non-cash and financing costs from the profitability measure. |
| | $\text{EBITDA Margin} = \frac{\text{EBITDA}}{\text{Net Sales}}$ |
| 2 | **PAT Margin** – Measures the final residual profit margin left for shareholders after all costs, including taxes. |
| | $\text{PAT Margin} = \frac{\text{Profit After Tax}}{\text{Net Sales}}$ |
| 3 | **Return on Equity (ROE)** – Shows how efficiently management uses shareholder capital to generate profit. |
| | $\text{ROE} = \frac{\text{Net Profit}}{\text{Average Net Worth}}$ |
| 4 | **Return on Capital Employed (ROCE)** – Measures the return generated on both debt and equity capital employed in the business. |
| | $\text{ROCE} = \frac{\text{EBIT}}{\text{Average Capital Employed}}$ |
| 5 | **Debt/Equity (D/E) Ratio** – Assesses the financial leverage and risk level of a company by comparing total debt to net worth. |
| | $\text{D/E Ratio} = \frac{\text{Total Adjusted Debt}}{\text{Net Worth}}$ |
| 6 | **Interest Coverage Ratio** – Determines how easily a company can pay interest on its outstanding debt from operating profits. |
| | $\text{Interest Coverage} = \frac{\text{EBIT}}{\text{Interest Expense}}$ |
| 7 | **Current Ratio** – Evaluates a firm's ability to meet short-term obligations using its current assets. |
| | $\text{Current Ratio} = \frac{\text{Current Assets}}{\text{Current Liabilities}}$ |
| 8 | **Quick Ratio** – A stricter liquidity test focusing on assets that convert to cash immediately, excluding inventories. |
| | $\text{Quick Ratio} = \frac{\text{Current Assets} - \text{Inventories}}{\text{Current Liabilities}}$ |
| 9 | **Dupont Analysis (ROE)** – Decomposes ROE into three components (profitability, efficiency, and leverage) to identify the drivers of returns. |
| | $\text{ROE} = \text{Net Profit Margin} \times \text{Asset Turnover} \times \text{Equity Multiplier}$ |

## Chapter 10: Valuation Principles

| No. | Term / Description |
| :---: | :--- |
| 1 | **Gordon Growth Model (GGM)** – Values a stock based on a perpetual stream of dividends growing at a constant rate, where $P_0$ is price, $D_1$ is next dividend, $k$ is discount rate, and $g$ is growth rate. |
| | $P_0 = \frac{D_1}{(k - g)}$ |
| 2 | **Cost of Equity (CAPM)** – Calculates required return on equity using the risk-free rate ($R_f$), beta ($\beta$), and market risk premium ($R_m - R_f$). |
| | $K_e = R_f + \beta \times (R_m - R_f)$ |
| 3 | **Weighted Average Cost of Capital (WACC)** – The average cost of all capital sources (equity and debt) used by a firm, where $W_e$ and $W_d$ are weights of equity and debt. |
| | $\text{WACC} = [K_e \times W_e] + [K_d \times (1 - \text{Tax}) \times W_d]$ |
| 4 | **PEG Ratio** – Adjusts the PE ratio to account for the company's expected earnings growth rate, providing a growth-adjusted valuation metric. |
| | $\text{PEG Ratio} = \frac{\text{PE Ratio}}{\text{Growth Rate}}$ |

## Chapter 12: Fundamentals of Risk and Return

| No. | Term / Description |
| :---: | :--- |
| 1 | **Return on Investment (ROI)** – A basic measure of profitability for a single period, expressed as a percentage of the investment. |
| | $\text{ROI} = \left( \frac{\text{Net Profit}}{\text{Investment}} \right) \times 100$ |
| 2 | **Compound Annual Growth Rate (CAGR)** – The smoothened annual growth rate of an investment over a multi-year period, where $n$ is the number of years. |
| | $\text{CAGR} = \left( \frac{\text{End Value}}{\text{Beginning Value}} \right)^{\frac{1}{n}} - 1$ |
| 3 | **Sharpe Ratio** – Measures excess return earned per unit of total risk (standard deviation, $\sigma_p$), where $R_p$ is portfolio return and $R_f$ is risk-free rate. |
| | $\text{Sharpe Ratio} = \frac{(R_p - R_f)}{\sigma_p}$ |
| 4 | **Treynor Ratio** – Measures excess return earned per unit of systematic risk (Beta, $\beta_p$), useful for evaluating diversified portfolios. |
| | $\text{Treynor Ratio} = \frac{(R_p - R_f)}{\beta_p}$ |
| 5 | **Jensen's Alpha** – Quantifies the active return added by a portfolio manager above the expected market return based on CAPM. |
| | $\alpha = R_p - [R_f + \beta_p \times (R_m - R_f)]$ |
